# Econometric projects

## UKDS data

The [ukds_data](https://github.com/tros01/econometrics_projects/tree/main/ukds_data) folder contains some generic but useful functions that allow us to work with datasets such as **Understanding Society** or **Labour Force Survey** directly from archives downloaded from the [**UK Data Service**](https://ukdataservice.ac.uk/). I have also defined functions that helpfully extract the data dictionary information into Python dictionaries, which allows us to locate, rename and recode variables in loops.
